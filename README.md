# hands-on-loop

技术传播/学习的最小单位是"亲手跑通"不是"听懂"的技能：10 分钟最小闭环（新技术不跑通不进决策）+ Cookbook 三件套（跑通即沉淀，攒 10 份=自己的工坊）+ handoff 交接协议（跨天/跨人/跨工具任务上下文变成可传递文件）+ 四角色分工（检索/执行/校验/呈现，质量来自独立校验角色）+ Vibe Coding 三条件 + 产出作品化/连接资产化。

一句话：**判断任何技术活动/课程/教程的价值只问一句——有没有让你手上产生一个能跑的产出。最好的技术传播，永远是实战。**

## 方法论底座

- 奥卡姆剃刀主题：所有项目名/环节/周边都是变量，常量只有一个——让开发者在最短时间内用预置环境和现成 Cookbook，把 AI 从"知道"变成"跑通"
- 实战优先：10 分钟从"看懂"到"跑通"产品级资讯看板；听懂不算数，跑通才算数
- 降低门槛：预置环境 + Cookbook + 充足 Token = 参与的真正门票；门槛不在知识，在开始前的那两小时配置
- 记忆不中断：跨会话、跨 Agent 的工作接续是 Agent 落地的下一个分水岭（玩具 vs 生产力）
- Vibe Coding：技术不再是瓶颈，领域理解才是；谁最懂场景谁就该动手
- 作品即简历：Bonjour 用作品自我介绍、DINQ 自然语言匹配候选人——能力可信度从履历描述迁移到可验证产出物
- 异质协作：4 个 bot 分工完成店庆策划——未来工作单位是"一个人调度一组分工明确的 Agent"
- 连接可复用：社交被产品化——先有可交换的数字名片/书面 Profile，再有连接与匹配

## 解决什么

| 痛点 | 本技能的做法 |
|---|---|
| 新技术评估全凭二手信息 | 10 分钟最小闭环闸门：单一产出+客观判据+时间盒；跑不通=判断全是二手的，不许进决策（标注"未亲测"） |
| demo 看完就忘/下次重来两小时 | Cookbook 三件套强制（环境+最小代码+可跑样例）；复用验收三步；攒 10 份=自己的工坊 |
| 跨会话/跨 Agent 上下文蒸发 | handoff 四要素文档（进度/失败路径/下一步唯一动作/约束）；handoff 链支持多 Agent 串行；交接前 30 秒自检 |
| 一个模型一口气干到底质量滑坡 | 四角色独立分工（检索/执行/校验/呈现）；校验独立上下文+只出清单不改稿+≤2 轮；质量来自校验角色不是提示词调优 |
| 懂业务的人写需求等排期 | Vibe Coding 三条件（高频+低风险+内部用）+领域专家动手；内部验证期后再谈对外 |
| 做完的事留在会话里没人知道 | 产出作品化（30 秒可验证的成品→作品页）+ 连接资产化（随时可发数字名片） |
| 学习节奏无抓手 | 每周 1 个闭环/每月 1 个多 Agent 真实任务/每季度更新作品页；判断标准：这个月手上多出了几个能跑、能展示的东西 |

## 安装

复制本目录到 `~/.agents/skills/`（或你的 Skill 加载路径）即可。

## 自检

```bash
python scripts/validate.py tests/sample_good.json   # 必须 exit 0
python scripts/validate.py tests/sample_bad.json    # 必须 exit 1
```

## 结构

```
SKILL.md                              工作流入口（一条主线 + 8 步流程 + 8 条硬规则）
references/loop-playbook.md           最小闭环设计：单一产出定义法（可打开/可判定/单一）、时间盒参数、超时分流（门槛缺陷记录）、Cookbook 完整模板+复用验收三步
references/handoff-protocol.md        交接协议：三触发条件（跨天/跨人/跨工具）、四要素模板、"下一步唯一动作"写法、失败路径记录法、多 Agent handoff 链、会话恢复四步
references/four-roles.md              四角色实操：每角色独立指令模板、上下文隔离方法、校验角色质量标准（差异清单格式）、不拆判据四条件/必须拆信号
references/gotchas.md                 10 个坑位（听懂就算学会/demo当跑通/只留代码不留环境/handoff写方向/校验自产自销/Vibe Coding选高风险/作品页只攒链接/连接不留描述/超时变无限重试/仪式感拆分）
scripts/validate.py                   技术跑通/学习计划七维校验器（exit 0/1/2）
tests/sample_good.json                通过基准（向量库 SDK 10 分钟闭环+12 份 Cookbook+完整 handoff+四角色独立+周报生成 Vibe Coding+30 秒可验证作品）
tests/sample_bad.json                 拦截基准(时间盒0/产出是"了解"/三件套缺/handoff写方向/缺校验角色/Vibe Coding选客户对账系统高风险对外/作品30秒验证不了/数字名片没更新)
docs/methodology.md                   方法论全文（奥卡姆剃刀 + 7 点核心提炼 + 7 步行动指南）
```
