# 交接协议：handoff 文档与跨会话接续

> 核心：**跨会话记忆接续是 Agent 落地的分水岭**——能不能把上下文、状态、进度交出去，决定了 Agent 是玩具还是生产力。handoff 文档就是把"记忆"从人脑和会话窗口里搬出来，变成可传递的文件。

## 一、什么时候必须写 handoff

三个触发条件（满足任一即必须写，不等任务结束）：

```
1. 跨天：今天做不完，明天继续
2. 跨人：交接给另一个人（或另一个 Agent）
3. 跨工具：从环境 A 挪到环境 B（换了电脑/换了 IDE/换了 Agent 会话）
```

**反例**：
- 任务结束时才写 → 细节已丢失，写的是"总结"不是"交接"
- 只在脑子里记 → 跨天即蒸发，接的人要重问一遍
- 写成"进展汇报" → 给老板看的，不是给接的人用的

## 二、四要素模板（缺一 = 接的人要重讲一遍）

```markdown
# Handoff: <任务名>
日期：<日期>  交接人：<谁>  接的人：<谁/哪个 Agent 会话>

## 1. 当前进度
已完成（可验证）：
  - <项>（产出物：<链接/文件/截图>）
未完成：
  - <项>（卡在：<具体卡点>）

## 2. 已试过的失败路径（别再踩）
  - 方案 A：<做法> → 失败原因：<具体原因>
  - 方案 B：<做法> → 失败原因：<具体原因>
  （这一节是最值钱的——接的人省下的是你踩过的坑）

## 3. 下一步唯一动作
  就一步：<动词开头的单个动作，如"把第 3 节的表格导入数据库" >
  完成判据：<做完的标准，客观可判定>

## 4. 约束条件
  - 预算/Token：<额度，剩多少>
  - 权限：<有什么、缺什么>
  - 截止：<时间>
  - 不可动：<哪些部分已经定了不许改>
```

### "下一步唯一动作"的写法

"唯一"是关键词：
```
✗ 方向："接下来优化性能"（接的人还要规划）
✗ 多步："先修 bug 再写测试再部署"（接的人要自己排序）
✓ 唯一："把 test_foo.py 第 42 行的 assert 阈值从 0.9 改成 0.85，跑通 pytest -k test_foo"
  判据："pytest 输出 PASSED"
```

接的人不需要再规划，只需要执行一步——规划是你的责任，不是接的人的责任。

## 三、失败路径记录法（第 2 节怎么写）

失败路径是 handoff 里最容易被省略、也最值钱的部分。记录格式：

```
做法：<具体到复制能复现的做法>
现象：<报错/结果的具体表现>
原因：<定位到的原因，没定位到就写"未定位">
结论：<所以别再走这条路/这条路在 X 条件下可以走>
```

**判据**：接的人读完第 2 节后，不会再问你"这个试过吗"——如果会问，说明记录不够具体（只写了"试过 A 不行"，没写怎么个不行法）。

## 四、跨 Agent 接续场景（多 Agent 协作前提）

原文"记忆不中断"工坊的同构：**多 Agent 协作能跑起来的前提是 handoff 协议**。

```
Agent A 会话 → [handoff 文档] → Agent B 会话
  传递内容 = 进度 + 失败路径 + 下一步唯一动作 + 约束
  不传递 = "我们刚才聊了什么"（会话窗口里的闲聊，对执行无用）
```

### handoff 链（多 Agent 串行）

```
任务 → A(检索) → handoff1 → B(执行) → handoff2 → C(校验) → handoff3 → D(呈现)
```

每个交接点一份 handoff，格式统一（四要素）。**校验 Agent 的输入 = 执行 Agent 的 handoff + 初稿**——校验者带着"已试失败路径"工作，才能区分"系统性盲区"和"随机错误"（见 four-roles.md）。

### 会话失效后的恢复

新会话（或第二天）启动时，第一动作是读 handoff，不是回忆：
```
1. 读 handoff 全文
2. 验证"当前进度"（产出物还在不在、状态对不对）
3. 执行"下一步唯一动作"
4. 做完后更新 handoff（进度/下一步/失败路径追加），再交接
```

**纪律**：handoff 是**活文档**——每完成一步就更新，不是任务结束才补写。不更新的 handoff = 过期的地图，比没有更危险（接的人信了过期信息）。

## 五、handoff 质量自检（交接前 30 秒）

```
[ ] 接的人只看这份文档（不问任何人），能开始执行"下一步唯一动作"吗？
[ ] 第 2 节有至少 1 条具体失败路径吗？（一条都没有 = 今天什么都没卡住，可疑）
[ ] "下一步"是动词开头的单步吗？
[ ] 约束里的预算/权限/截止是具体数字吗？
```

任一不过 = 补完再交。交接出去的 handoff 质量，决定下一个会话（或下一个人）的启动成本——启动成本从 0（读文档直接干）到 2 小时（重问一遍重来一遍），差的就是这份文档。
